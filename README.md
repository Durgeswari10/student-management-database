
# SQL Data Analysis Internship - Student Management Database

📄 **[View & Download the Project Report (PDF)](./StudentManagement.pdf)**

This project is a part of my **SQL Data Analysis Internship (Task 1)** at **Maincrafts Technology**. It demonstrates how to set up a relational database, populate it with records, and run analytical queries to extract student performance insights.

## 🛠️ Skills Gained & Applied
* **Database & Table Design:** Created structural relations with Primary Keys and auto-increment properties.
* **Data Manipulation (DML):** Managed records using `INSERT` and `UPDATE` statements.
* **Data Aggregation:** Analyzed grouped metrics using `AVG()`, `COUNT()`, and `MAX()`.
* **Data Filtering:** Extracted conditional subsets using `WHERE`, `GROUP BY`, and mathematical logical expressions.

## 🚀 How to Run This Project Locally

### Prerequisites
* MySQL Server (v8.0 or higher)
* MySQL Workbench or any preferred CLI/GUI client

### Execution Steps
1. Clone this repository or download the `.sql` files.
2. Open your MySQL client and connect to your local server.
3. Execute the code inside `StudentManagement.sql` to build the database and run the queries.
